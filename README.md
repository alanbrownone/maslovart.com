# maslovart.com

Temporary preview of Guennadi Maslov's new website, showing the look and feel.
It is plain HTML with no build step, so Netlify can publish this folder as-is.

- `index.html` is the landing page that links to the desktop and mobile previews.
- `desktop.html` shows the site full-width.
- `mobile.html` shows the site inside a phone-sized frame.
- `site.html` is the site itself (images are embedded in the file).

These files came from `MaslovArt_WebsiteSpecs.afpub.zip`.
